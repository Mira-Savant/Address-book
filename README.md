A console-based Address Book application developed in C for managing contact information.

Features
Add a new contact
Search for a contact
Edit existing contact details
Delete a contact
Display all contacts
Store and retrieve contact information using file handling
Validate contact details
Technologies Used
C Programming
Structures
Functions
Pointers
File Handling
Modular Programming


How It Works
The application provides a menu-driven interface through which the user can manage contacts.
The user can:
Add a contact
Search for a contact
Edit contact details
Delete a contact
Display saved contacts
Exit the application

Contact information is stored using file handling, allowing the data to be retained between program executions.

This project demonstrates practical implementation of:
C programming concepts
Structures and pointers
Functions and modular code organization
File handling
Menu-driven application design
Input validation
